조직도를 기본으로 inveni 의 agent 등록 통계 대시보드를 만들고 싶어. 
조직도는 펼치기 버튼을 가지고 있어야 하고 조직별/개인별 agent 등록 건수, 
github이름과 조직도를 mapping해서 organization에 등록된 건수를 보여주는 웹사이트를 만들어줘.
github mapping 되면, 그들이 등록한 repository 이름과 readme 파일을 읽어서, agent이름과 agent 설명을 추가로 넣어줘.
그리고 여기에 개인별 repository 최초등록일, 최종수정일 필드 추가해 줘
마지막으로 여기에 올린 파일을 대시보드에서 실행할 수 있도록 실행버튼 만들어줘
서버 띄워서 웹페이지로 보여줘

만들어진 사이트는 우리 임직원들이 github에 올린 agent를 모니터링 하기 위한 목적으로 만든거야. 너가 생각할 때 이 사이트에 추가할 수 있는 기능이 뭐가 있는지 나에게 질문해주고 답변을 바탕으로 기능 넣어서 새로 띄워저

사이트 목적
최근 활동 피드 - 조직 전체에서 최근 등록된/수정된 agent를 시간순 타임라인으로 보여줘서,
                       누가 언제 새 agent를 올렸는지 한눈에 파악
검색/필터 - 이름, 부서, github 아이디, agent명으로 빠르게 찾기, 인원이나 레포가 늘어날수록 
                필요성이 커짐
부서별 등록 현황 시각화 - 본부/부서별 등록 건수를 막대그래프로 비교해서, 어느 팀이 활발히 참여하고
                                   있는지 한눈에 파악
방치된/미준수 레포 경고 - Readme 템플릿을 안 넣거나 오랫동안 업데이트가 없는 레포를 자동 감지해서
                                   목록으로 보여줌

텔레그램 봇 토큰과 chat_id 는 telegram-mcp/.env 파일에 넣고
서버가 시작할 때 그 파일에서 읽게 해줘. (.gitignore 에도 추가)
등록 명령어에는 토큰이 들어가지 않게 해줘.

웹사이트 통계정보에서 전체인원/github 매핑인원/org 레포지토리 수/총 등록건수/방치/미준수 정보영역 클릭하면 팝업창으로 상세정보 보여줘

등록된 agent가 실제로 정상 동작하는지 여부를 나타내 주고 보안 취약점 감지 추가해주고
최근 커밋/라이선스/빌드 상태를 이미지 배지로 예쁘게 표시해줘

빌드 상태 (실제 동작 여부): 각 레포의 최근 GitHub Actions 실행 결과를 조회해 passing/failing/in progress/no CI 배지로 표시. CI가 없는 레포는 "no CI"로 구분(실패로 오인하지 않도록)
보안 취약점 감지: GitHub Dependabot alerts API로 오픈된 취약점 개수를 조회. 조회 권한/설정이 안 된 레포는 "unknown"으로 별도 표시(0건과 혼동 방지). 취약점이 있거나 빌드가 실패한 레포는 "방치/미준수" 경고 섹션에도 자동으로 사유가 추가됨 (예: "빌드 실패", "보안 취약점 2건")
shields.io 배지: 빌드/라이선스/보안/최근 커밋 4종을 다크 테마에 맞춘 색상의 이미지 배지로 표시 (agent 카드 내부 + "Org 레포지토리 수" 팝업 상세 테이블에도 반영)
실제로 .github 레포로 확인해보니 build: no_CI, license: none, security: no known issues, last commit: 1d ago 배지가 정상적으로 떴습니다. 레포에 GitHub Actions 워크플로우가 생기면 자동으로 passing/failing 배지로 바뀝니다.
